# TP2 — Structures de contrôle (2h)

## Objectifs
- Maîtriser `if/else`, `switch`, `for`, `while`, `do while`.

## Exercice 1 — Validation de saisie

Demander un âge à l'utilisateur en boucle (`do while`) jusqu'à obtenir une valeur entre 0 et 120.

## Exercice 2 — Table de multiplication

Afficher la table de multiplication d'un nombre saisi par l'utilisateur, de 1 à 10, avec une boucle `for`.

## Exercice 3 — Nombres premiers

Écrire un programme qui affiche tous les nombres premiers entre 2 et un nombre N saisi par l'utilisateur (algorithme naïf par divisions successives).

## Exercice 4 — Menu interactif

Créer un menu avec `switch` proposant :
1. Calculer une factorielle
2. Vérifier si un nombre est premier
3. Convertir Celsius/Fahrenheit
4. Quitter

Le menu doit se réafficher (boucle `while`) tant que l'utilisateur n'a pas choisi « Quitter ».

## Exercice 5 — FizzBuzz

Afficher les nombres de 1 à 100 ; remplacer les multiples de 3 par `Fizz`, les multiples de 5 par `Buzz`, les multiples de 15 par `FizzBuzz`.

## À rendre

Fichier `tp2.c`, testé avec plusieurs jeux de valeurs (y compris valeurs limites : 0, négatifs, très grands nombres).
