# Chapitre 3 — Structures de contrôle

### Algorithmique et Programmation en C

---

## 1. Structures conditionnelles

### `if / else if / else`

```c
int note = 12;
if (note >= 16) {
    printf("Très bien\n");
} else if (note >= 10) {
    printf("Admis\n");
} else {
    printf("Ajourné\n");
}
```

### `switch`

```c
int jour = 3;
switch (jour) {
    case 1: printf("Lundi\n"); break;
    case 2: printf("Mardi\n"); break;
    case 3: printf("Mercredi\n"); break;
    default: printf("Jour invalide\n");
}
```

L'oubli d'un `break` provoque un **fall-through** vers le cas suivant : parfois voulu, souvent source de bug. Toujours documenter un fall-through intentionnel par un commentaire.

### Opérateur ternaire

```c
int max = (a > b) ? a : b;
```

---

## 2. Boucles

### `while`

```c
int i = 0;
while (i < 5) {
    printf("%d\n", i);
    i++;
}
```

### `do ... while`

Exécute le corps au moins une fois avant de tester la condition — utile pour valider une saisie utilisateur.

```c
int choix;
do {
    printf("Choix (1-3) : ");
    scanf("%d", &choix);
} while (choix < 1 || choix > 3);
```

### `for`

```c
for (int i = 0; i < 10; i++) {
    printf("%d ", i);
}
```

---

## 3. Rupture de séquence

- `break` : sort immédiatement de la boucle ou du `switch`.
- `continue` : passe directement à l'itération suivante.
- `goto` : à éviter en général (nuit à la lisibilité), sauf cas très spécifiques (sortie d'imbrications profondes, gestion d'erreurs façon « cleanup » en C bas niveau).

---

## 4. Boucles infinies et conditions de terminaison

```c
for (;;) {
    // boucle infinie volontaire, sortie via break
}
```

Une condition de terminaison mal posée (ex. compteur non incrémenté, condition toujours vraie) provoque un déni de service par consommation de ressources — un cas particulier à garder en tête pour le cours *Security by design*.

---

## 5. Complexité algorithmique (introduction)

Le nombre d'itérations d'une boucle détermine la complexité temporelle d'un algorithme, notée en notation de Landau (grand O). Exemple : une recherche séquentielle dans un tableau de taille *n* est en O(n) ; une recherche dichotomique dans un tableau trié est en O(log n). Cette notion sera réutilisée pour analyser le coût des algorithmes cryptographiques (chapitre Cryptographie) et des attaques par force brute (chapitre Cryptanalyse).

---

## À retenir

- Choisir la structure adaptée : `for` pour un nombre d'itérations connu, `while`/`do while` pour une condition dynamique.
- Toujours s'assurer qu'une boucle progresse vers sa condition d'arrêt.
- `switch` sans `break` = piège classique.
